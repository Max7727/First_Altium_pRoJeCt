# First_Altium_pRoJeCt
Altium-Learning-Project - Altium 25.8.1

The sole purpose of this project is to learn Altium and GitHub functionality.

This "pRoJeCt" is **just** a foundation for future, more impressive, and technically advanced projects.

The goal is to create a fully functioning, production-ready project which could be understood and manufactured by profesional PCB services, like JLCPCB.





# Update
## What i have done

I have successfully created a simple but fully functional PCB design project.

After generating all the necessary output files (Gerber files, drill file, BOM file), this project is ready to be sent for manufacturing to a professional PCB service, like JLCPCB.
